Summary

Conan Exiles is an online multiplayer open world survival game with a nice base construction system, cool captureable NPCs and an unrestrictive climbing system.

Project Details

Big professional project built using Unreal Engine 4. It is heavily modable. Has private servers that can be hosted by players. Can be played online, or in single player/coop mode.

Available on PC, XBox Series X and S, and PlayStation 4.

My Contribution

I worked as a game engine programmer on Conan Exiles for 6 months: mainly fixing bugs and improving performance while learning my way around. I mostly worked on the server list and the offline mode for the main menu.
