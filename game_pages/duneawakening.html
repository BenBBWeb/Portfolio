Summary

Dune: Awakening is an Online Multiplayer Open World Survival RPG with a persistent world and complex server architecture.

Project Details

Big professional project built using Unreal Engine 5. It is made of multiple openworld maps, each run by a separate server app, connected together via an overmap. One of the maps launched as a grid of 3x3 servers with seamless server border transitions.

Some of its key features are: state of the art building system, many different multicrew vehicles, cool movement abilities, dynamic events...

Available on PC and Steam Deck.

My Contribution

As a game engine programmer I have tailored our version of Unreal Engine 5 for the needs of our project.

I have participated in many features such as Live Services, Telemetry, Mutable, and more.
